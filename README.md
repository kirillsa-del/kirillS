Приложение «Random Quote Generator» — это GUI‑приложение на Python с использованием библиотеки Tkinter. Оно позволяет:
* генерировать случайные цитаты из предопределённого списка;
* просматривать историю сгенерированных цитат;
* фильтровать цитаты по автору и теме;
* сохранять и загружать историю и цитаты из JSON‑файла.


* Генерация цитат: кнопка «Сгенерировать цитату» выбирает случайную цитату с учётом фильтров.
* История: отображает последние 20 сгенерированных цитат.
* Фильтры: возможность фильтрации по автору и теме.
* Сохранение данных: история и цитаты сохраняются в `quotes_data.json`.
